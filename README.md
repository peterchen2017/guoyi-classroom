# 乐昌国艺书院 · 机房课堂管理（一期）

**版权所有 © 乐昌国艺书院    开发者：陈老师**

老师在机房管理本班已安装客户端的 Windows 学生机。只有老师点击「开始上课」后才传送屏幕，「下课」后立即停止。学生机始终显示「课堂管理运行中」窗口或托盘图标。

**不做**键盘记录、剪贴板读取、隐藏进程、课后继续抓屏或继续控制、校外访问。上课期间，老师可在「查看屏幕」窗口中选择「远程控制」操作该学生机（需教师机和学生机都升级到 1.2.7）；学生机会显示醒目横幅「老师正在控制本机」。默认只看不控。下课、关闭查看窗口或点「停止控制」立即停止。

支持系统：**Windows 7 SP1 / 8.1 / 10 / 11**（同时提供 64 位和 32 位安装包与绿色版）。教师机使用软件自带的主窗口上课，不必预装浏览器。手机只需和教师机在同一机房 WiFi，用浏览器打开网页控制台，不用装 App。

## 一、安装（教师机 / 学生机）

安装包和绿色版都在 `dist/` 目录。请按电脑的 **32 / 64 位** 选用对应包：

- 查看方法：打开「计算机」（或「此电脑」）→ 右键「属性」→ 看「系统类型」。
- 写着「64 位操作系统」：用 **x64** 包（优先）。
- 写着「32 位操作系统」：必须用 **x86** 包，**不要用 x64**，否则会装不上或打不开。
- 很多机房的 Windows 7 是 32 位，请不要只发 x64 包。

| 用途 | 64 位（x64） | 32 位（x86） |
| --- | --- | --- |
| 教师机安装包 | `乐昌国艺书院-机房课堂管理-教师机-安装包-x64.exe` | `……教师机-安装包-x86.exe` |
| 学生机安装包 | `乐昌国艺书院-机房课堂管理-学生机-安装包-x64.exe` | `……学生机-安装包-x86.exe` |
| 教师机绿色版 | `……教师机-绿色版-Win7-x64.zip`（英文名 `Guoyi-Teacher-Win7-x64.zip`） | `Guoyi-Teacher-Win7-x86.zip` |
| 学生机绿色版 | `……学生机-绿色版-Win7-x64.zip`（英文名 `Guoyi-Student-Win7-x64.zip`） | `Guoyi-Student-Win7-x86.zip` |

安装包已内置 **Python 3.8.10**，以及 Win7 常缺的 **UCRT / VC++ 运行库 DLL**（`ucrtbase.dll`、`api-ms-win-crt-*.dll`、`msvcp140.dll` 等），一般**不必再手动安装 Python、不必先打 KB2999226**。

**默认安装到当前用户目录**（`%LOCALAPPDATA%\GuoyiClassroom\Teacher` 或 `Student`，例如 `C:\Users\老师\AppData\Local\GuoyiClassroom\...`），**不需要管理员权限**。卸载信息写在当前用户注册表。若以前用旧包在「Program Files」下安装失败，请改用本版安装包或绿色版，不要继续用旧的管理员安装包。

### 教师机

1. 在教师机上双击对应位数的「教师机-安装包」，按向导安装（无需管理员）。
2. 安装结束后可勾选立即启动，或双击桌面上的 **「机房课堂管理-教师机 1.2.7」**。
3. 服务就绪后会打开软件自己的教师主窗口（顶部工具栏，下方学生名单和屏幕墙）。**不必预先安装 Chrome 或 Edge**，程序也不会自动打开浏览器。窗口标题带有「1.2.7」。同时可能有一个黑色控制台窗口显示本机局域网 IP 和日志。**关闭教师主窗口即退出**（会先确认）。
4. 用默认教师账号在主窗口登录（见下方），登录后立刻点击「改密码」。
5. 主窗口会显示本机局域网 IP。把 `http://教师机IP:8765` 告诉自己（手机访问）和学生（必要时手填 IP）。也可点主窗口上的「在浏览器打开（手机用）」作为备用，但不依赖浏览器才能上课。
6. 安装程序会**尝试**放行防火墙 **TCP 8765**、**UDP 8766**；没有管理员权限时这一步可能失败，但安装仍会完成。若手机或学生机连不上，请在「Windows 防火墙」中允许该程序或这两端口，或请有管理员权限的老师协助。

### 学生机

1. 在每台学生机上双击对应位数的「学生机-安装包」安装（无需管理员）。
2. 可勾选「开机自动启动」。
3. 安装后桌面会出现 **「机房课堂管理-学生机」**，双击后出现「课堂管理运行中」窗口（以及托盘图标）。
4. 在连接窗口填写：学生姓名或机位号、教师机 IP，课堂加入码可选（老师主窗口顶部可见）。也可点「自动发现」（需同一局域网且教师端已启动）。
5. 无加入码时，老师在主窗口点「允许加入」后才会进入课堂。
6. 以后若要改 IP 或姓名：开始菜单 → 乐昌国艺书院 → **更改连接设置**。

### 免安装绿色版（解压即可运行）

若安装向导仍然失败，或希望先试用：把绿色版 zip 解压到**较短路径**（建议 `C:\GuoyiTeacher` 或 `C:\GuoyiStudent`），再双击 `start_teacher.cmd` / `start_student.cmd`。不必管理员。个别 Win7 处理中文文件名不顺利时，请改用英文短文件名那一份（如 `Guoyi-Teacher-Win7-x64.zip`）。

### 手机（机房 WiFi）

在手机浏览器打开：`http://教师机局域网IP:8765`（与教师机同一 WiFi）。登录同一教师账号后，可看屏幕墙、点开单人画面、锁屏/解锁、发公告。先不做独立 App，也不能在校外访问。网页控制台请用手机自带浏览器，不要用 Internet Explorer。

## 三、上课怎么用（一期功能）

1. 学生机连上后，主窗口左侧显示名单和在线状态。带加入码的会自动批准，否则点「允许加入」。
2. **必须先点「开始上课」**，已加入且在线的学生才会出现在屏幕墙（先显示「等待画面…」，收到画面后再换成真实屏幕）。未开课时屏幕墙会用大字提示：「请先点左上角「开始上课」，学生机才会传来画面」。点卡片或「查看屏幕」会提示先开课，不会打开空窗口。
   打开某学生的「查看屏幕」后，默认为只看不控；再点「远程控制」才可以把鼠标和键盘发到该学生机（一次只控制一台）。学生机顶部会出现「老师正在控制本机」。点「停止控制」、关闭查看窗口或下课立即停止。两端都要装 1.2.7，旧 1.2.6 学生端会忽略控制消息且不崩溃，但无法被控制。
3. **锁屏全部** 会在学生机弹出置顶全屏「请看老师」（只能由老师解锁，下课也会自动解开）。
4. 可发公告、发题目、把文件发到学生机（保存在学生机「课堂文件」文件夹）。
   **发文件支持 C++ 代码**（`.cpp` `.h` `.hpp` `.cc` `.cxx` `.c` `.h++`）以及 `.txt` `.in` `.out` `.md` 等常见资料（也可发其它类型）。学生可用资源管理器打开。通过本课堂软件下发的资料**不受**上网限制拦截。
5. **广播教师屏幕**：在教师机本机启动时，服务端会用 Windows 7 就有的 GDI BitBlt 采集教师屏幕。若采集失败，可用「广播图片」上传一张图。广播走服务端已有的 GDI 采集，不是浏览器的屏幕捕获。主窗口也可点「广播图片」上传一张图。
   主窗口工具栏有醒目的 **「缩小屏幕」** 勾选：勾选后向学生广播缩小后的画面（最长边约 800 像素），节省带宽，学生窗口更合适；取消勾选即恢复原大小。
6. **限制网页游戏和随意下载**：点「开始上课」后默认开启，主窗口可在下课前临时关闭。下课或关闭限制后，学生机恢复原来的网络设置，不会把代理留在机器上。学生机可见提示「上课期间已限制网页游戏和下载」。
   默认拦截 4399、7k7k、3366、2144 等小游戏门户，以及常见网盘/下载站；并拦截 `.exe` `.msi` `.bat` `.cmd` `.scr` `.zip` `.rar` `.7z` `.iso` `.apk` `.torrent` 等下载（HTTP 可看路径，HTTPS 只按域名拦截，**不解密、不装证书**）。老师可在「编辑限制名单」中增删域名，或把教学网站加入白名单。教师机地址、课堂控制台和学生收文件始终放行。
7. **设置默认桌面**：主窗口「设置默认桌面」可上传 jpg / png / bmp 壁纸，一键下发到已加入（在线或之后重新连上）的学生机并设为桌面背景。默认同时开启「锁定桌面」：学生不能通过系统个性化或桌面右键更改壁纸（使用 Windows 7 即有的 `SPI_SETDESKWALLPAPER` 和 HKCU 策略 `NoChangingWallpaper`、`NoDispBackgroundPage`）。锁定状态与上课无关，下课或学生机重启后仍然保持，直到老师点「解除桌面锁定」。解除后会尝试恢复该学生机锁定前保存的壁纸和策略。学生端启动时若仍处于锁定，会重新应用壁纸。
8. 点 **下课**：学生机立刻停止传屏并关闭上网限制、还原网络设置，服务器丢弃画面缓存。默认桌面锁定不会因下课而解除。

## 四、Windows 7 兼容说明与运行库

| 项目 | 策略 |
| --- | --- |
| 编程语言 | Python 3.8 语法（Win7 官方最后支持的版本是 3.8.10） |
| 安装包 | 内置官方嵌入式 Python 3.8.10，老师通常不用再装 Python |
| 截屏 | GDI `BitBlt` / `GetDIBits`（Win7 即有）。**不用** Windows.Graphics.Capture（Win10 才有） |
| 锁屏 | 置顶全屏 Win32 窗口 |
| 托盘 | `Shell_NotifyIcon`（Win7 即有） |
| 界面工具包 | 不依赖 WinUI、.NET 5+、tkinter（嵌入式 Python 不含 Tk） |
| 手机网页控制台 | 避免可选链、`??`、ES2022+；请用手机浏览器或 Chrome / Edge，不支持 IE。教师机使用原生窗口，不必打开此页 |
| Visual C++ / UCRT | 安装包和绿色版已内置官方可再发行 DLL：`ucrtbase.dll`、`api-ms-win-crt-*.dll`、`vcruntime140.dll`、`msvcp140.dll` 等（来自微软 VC++ 2015–2022 运行库与 Windows SDK Universal CRT Redistributable）。Win7 不必先自行安装 KB2999226 或 VC 运行库。64 位包装 x64 DLL，32 位包装 x86 DLL。 |

Windows 10 / 11 同样使用这套安装包即可。本软件需要 **Windows 7 SP1** 或更高版本（未打 SP1 的 Win7 仍可能无法运行）。

若启动失败：先确认系统是 32 还是 64 位并换用对应的包；再改用绿色版解压到短路径（如 `C:\GuoyiTeacher`）后双击 `start_teacher.cmd`。

教师机 Windows 7 上若窗口一闪或弹出错误，请把安装目录下的 `start_teacher.log` 发给开发者（可用记事本打开）。默认目录：

`C:\Users\用户名\AppData\Local\GuoyiClassroom\Teacher`

学生机日志为同级 `Student` 目录下的 `start_student.log`。已经在 Windows 10 / 11 上正常使用 1.2.1 学生端的电脑不必立刻重装；远程控制必须使用 1.2.7 学生端；Windows 7 请使用 1.2.7 或更新包。已装 1.2.6 的教师机和学生机都需要升级到 1.2.7。

1.2.2 起 Windows 安装包改用 FastAPI 0.99 + Pydantic v1 纯 Python 轮子，**不再包含 `pydantic-core`**。1.2.1 教师机在 Win7 上会因 `_pydantic_core` 加载失败（「找不到指定的程序」）而无法启动。

1.2.3 修复覆盖安装：安装程序会先结束本安装目录中的旧进程，并清理旧的启动脚本、应用代码和内置 Python（含 site-packages 里残留的 pydantic / pydantic_core），再复制新文件。保留安装目录下的日志和 `data\`（若有），不触碰安装目录以外的课堂数据或学生作业。窗口标题和启动日志会写明版本号，便于从截图判断是否已装上新版。升级前可先卸载旧版；若仍看到 `_pydantic_core` 或 `launch_teacher.py` 行号仍是旧版（`main` 在 30 行左右），说明还在运行旧程序，需卸载后重装。

1.2.4 为教师机增加了 Win32 原生主窗口：服务就绪后直接在软件内登录并完成上课、屏幕墙、锁屏、公告、发文件、广播教师屏幕（含缩小屏幕，走现有 GDI 采集）、限制网页、设置默认桌面等全部操作，教师机不必预装、也不再自动打开 Chrome / Edge / IE。手机在机房 WiFi 下仍可使用原有网页控制台。

1.2.5 修正 Win7 / Python 3.8 下 ctypes.wintypes 没有 HCURSOR 导致教师窗口无法打开的问题。学生端「加入课堂」对话框使用同一套窗口类定义，已一并修复。

1.2.6 修正登录失败提示（显示「账号或密码不正确」，不再误报「登录已过期」）；登录窗口支持记住密码（本机 DPAPI 加密保存，仍需点登录）；可重置为默认密码。

1.2.7 修复屏幕墙：未开课时有明确空状态提示；开课后立即为已批准在线学生建卡片（不必等第一帧），取屏失败显示文字而不是空白格；缩略图先到、格子未建时会缓存画面并重试。教师窗口改为分组且可换行的工具栏（「开始上课」更显眼），配色更接近课堂软件。新增上课时可选的远程控制（查看屏幕窗口内开启，学生机有醒目横幅）。教师机和学生机都需要升级到 1.2.7。

## 八、已知限制

- 手机网页控制台必须与学生机在同一机房局域网，一期不做校外中转。教师机使用软件主窗口，不必打开网页。
- Windows 7 的 IE 无法使用网页控制台（仅手机或备用浏览器需要）；教师机不再依赖浏览器。
- 广播以教师机本机 GDI 采集或「广播图片」为准，不使用浏览器的屏幕捕获 API。
- 上网限制依赖 Windows 系统代理（WinINET），对会使用系统代理的 IE / 部分 Chrome / Edge 生效。便携浏览器自带代理、Firefox 默认不用系统代理、VPN、自己改 hosts 或手动关掉系统代理，仍可能绕过；**不保证 100% 封死**。HTTPS 只按主机名/SNI 拦截，不会安装证书或解密流量。
- Linux / 模拟模式没有全屏锁屏覆盖层和托盘，只打印状态并发送素色模拟帧；Linux 上验证过滤逻辑和本机代理，不修改系统代理。默认桌面在 Linux 上为模拟实现（记录要设置的图片、锁定开关、解锁后恢复），不调用 Windows API。
- 默认桌面锁定写入当前用户（HKCU）策略，并定期检测壁纸是否被改回。若学生账户具有管理员权限，仍可能自行改注册表或用其他工具解除；这是已知限制，机房应使用普通学生账户。不禁止移动桌面图标。
- 嵌入式运行库不包含 tkinter，Windows 界面走纯 Win32 API。
- 学生仍可用 Ctrl+Alt+Del 等系统方式切出锁屏（有意为之，避免做成无法退出的隐蔽软件）。
- 一期不含：收取作业、课后简报。远程控制仅在上课且老师主动开启时可用，不做键盘记录。

- `tests/test_desktop.py` 默认桌面锁定验证
- `乐昌国艺书院-机房课堂管理-使用说明.txt` 给老师的简要使用说明（UTF-8 BOM）
