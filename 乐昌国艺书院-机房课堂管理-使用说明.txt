乐昌国艺书院 · 机房课堂管理 使用说明
版权所有 © 乐昌国艺书院    开发者：陈老师
支持系统：Windows 7 SP1 / 8.1 / 10 / 11（请按 32 / 64 位选用对应软件包）

本软件用于老师在机房管理本班已安装客户端的学生电脑。
只有老师点击「开始上课」后才传送屏幕，「下课」后立即停止。
学生机始终显示「课堂管理运行中」窗口或托盘图标。
不做键盘记录、不读取剪贴板、不隐藏程序、不下课后继续抓屏、不远程操控学生机、不支持校外访问。


一、先看电脑是 32 位还是 64 位

1. 打开「计算机」（或「此电脑」）→ 右键「属性」→ 看「系统类型」。
2. 写着「64 位操作系统」：用文件名带 x64 的安装包或绿色版（优先）。
3. 写着「32 位操作系统」：必须用文件名带 x86 的包，不要用 x64，否则会装不上或打不开。
   很多机房的 Windows 7 是 32 位，请不要只发 64 位包。
4. 本软件需要 Windows 7 SP1 或更高版本。未打 SP1 的 Win7 可能仍然无法使用。


二、安装（无需管理员）

本版安装包默认装到当前用户目录，例如：
  C:\Users\你的用户名\AppData\Local\GuoyiClassroom\Teacher
  C:\Users\你的用户名\AppData\Local\GuoyiClassroom\Student
不需要管理员权限，也不会再默认装到 Program Files。

若以前用旧安装包失败（需要管理员、或装完打不开），请改用本版新安装包，或改用下面的绿色版。

1. 教师机：双击「乐昌国艺书院-机房课堂管理-教师机-安装包-x64.exe」（32 位电脑改用 x86）。
2. 学生机：在每台学生电脑上双击对应的「……学生机-安装包-……」。可勾选「开机自动启动」。
3. 安装包已内置运行库（含 Win7 常缺的 ucrtbase.dll 等），一般不必再安装 Python，也不必先打系统补丁 KB2999226。
4. 若仍提示缺少 VCRUNTIME 或 api-ms-win-crt 之类文件，请确认用的是本版新包，并核对数位（32/64）是否选对。
5. 教师机和手机查看控制台时需要浏览器，请使用 Chrome 或新版 Edge，不要用 Internet Explorer。
   Windows 7 请安装 Chrome 109（Win7 能用的最后一版）。
   学生机只要安装客户端，上课不需要再开浏览器。


三、免安装绿色版（解压即可运行）

如果安装向导仍然失败，请使用绿色版 zip：

  教师机 64 位：乐昌国艺书院-机房课堂管理-教师机-绿色版-Win7-x64.zip
             （英文短文件名：Guoyi-Teacher-Win7-x64.zip）
  教师机 32 位：Guoyi-Teacher-Win7-x86.zip
  学生机 64 位：Guoyi-Student-Win7-x64.zip
  学生机 32 位：Guoyi-Student-Win7-x86.zip

请解压到较短的路径，例如 C:\GuoyiTeacher 或 C:\GuoyiStudent，然后：
  教师机双击 start_teacher.cmd
  学生机双击 start_student.cmd

不必管理员，也不必先安装 Python。
个别 Win7 电脑处理中文文件名不顺利时，请改用上面的英文短文件名压缩包。


四、教师机怎么用

1. 双击桌面上的「机房课堂管理-教师机」（绿色版则双击 start_teacher.cmd）。
2. 会弹出一个黑窗口和一个「课堂管理运行中」小窗口（里面会显示本机局域网 IP），
   并在服务就绪后自动用浏览器打开：
   http://127.0.0.1:8765
   只关掉浏览器不会退出课堂管理；请关闭黑色控制台窗口来退出。
3. 默认账号：teacher
   默认密码：ChangeMe@2026
   登录后请立刻点击右上角「改密码」。
4. 把黑窗口里显示的地址发给自己的手机（需要时）：
   http://教师机IP:8765
   例如：http://192.168.1.10:8765
5. 若学生机或手机连不上：确认同一机房局域网，并检查 Windows 防火墙是否放行 TCP 8765、UDP 8766。
   没有管理员权限时，安装程序可能无法自动添加防火墙规则，需要老师手动允许或请机房管理员协助。


五、学生机怎么用

1. 双击桌面上的「机房课堂管理-学生机」，会出现「课堂管理运行中」窗口（以及托盘图标）。
2. 填写：学生姓名或机位号、教师机 IP。课堂加入码可选（在老师控制台顶部可以看到）。
   也可点击「自动发现」（需同一局域网，且教师端已启动）。
3. 没有加入码时，老师要在控制台点击「允许加入」，学生机才会进入课堂。
4. 以后若要改 IP 或姓名：开始菜单 → 乐昌国艺书院 → 更改连接设置。
5. 若已勾选开机启动，学生机开机后会自动运行并显示「课堂管理运行中」。
   如果老师已设置并锁定了默认桌面，开机后会重新应用，学生不能自行改掉。


六、手机怎么用（机房同一 WiFi）

在手机浏览器打开：http://教师机局域网IP:8765
用同一个教师账号登录后，可查看屏幕墙、点开单人画面、锁屏/解锁、发公告。
不用安装 App，也不能在校外访问。


七、上课操作

1. 学生机连上后，控制台左侧显示名单和在线状态。
   带加入码的会自动批准，否则请点「允许加入」。
2. 点击「开始上课」，屏幕墙开始出现学生屏幕缩略图；点某个学生可放大查看。
3. 「锁屏全部」会在学生机弹出置顶全屏「请看老师」（由老师解锁，下课也会自动解开）。
   学生仍可用 Ctrl+Alt+Del 等系统方式切出（这是有意保留的，避免无法退出）。
4. 可以发公告、发题目，并把文件发到学生机（保存在学生机「课堂文件」文件夹，可用资源管理器打开）。
   支持发送 C++ 代码文件，例如 .cpp .h .hpp .cc .cxx .c，以及 .txt .in .out .md。
5. 广播教师屏幕：教师机本机会采集桌面再发给学生（不是浏览器的「共享屏幕」）。
   可勾选「缩小屏幕」，把画面缩小后再发给学生，取消勾选即恢复原大小。
   若采集失败，可用「广播图片」上传一张图。
6. 点击「下课」：学生机立刻停止传屏，上网限制也会关闭并恢复学生机原来的网络设置。
   注意：默认桌面锁定不会因为下课而解除。


八、限制网页游戏和随意下载

1. 老师点击「开始上课」后，默认开启「限制网页游戏和随意下载」。
2. 上课期间可在控制台临时关闭或重新打开；关闭或下课后，会还原学生机原来的系统代理，不留规则。
3. 默认会拦截常见网页游戏站点（如 4399、7k7k、3366、2144 等）以及常见下载站/网盘；
   也可拦截常见安装包和压缩包下载（如 .exe .zip .rar 等）。
4. 老师通过本课堂「发文件」下发的资料（包括 C++ 代码）不受影响。
5. 可在控制台编辑拦截域名名单。
6. 学生机上会显示「上课期间已限制网页游戏和下载」一类提示。
7. 说明：此限制对使用系统代理的 IE、部分 Chrome 和 Edge 有效。
   便携浏览器、Firefox 默认设置、VPN、或学生手动关闭代理时，仍可能绕过，不能保证百分之百封死。


九、设置默认桌面（学生不可以改）

1. 在教师控制台工具栏点击「设置默认桌面」，选择一张 jpg、png 或 bmp 图片。
2. 默认勾选「锁定桌面（学生不能更改壁纸）」，再点「下发并应用」。
   已连上并加入课堂的学生机会立刻更换壁纸；当时离线、之后再连上或开机启动的学生机也会自动应用。
3. 锁定后，学生不能通过 Windows 个性化、桌面右键「个性化」等更改壁纸。
   若壁纸仍被改掉，学生端会定期检测并恢复为老师设置的默认桌面。
4. 此锁定是机房统一环境，与是否正在上课无关。下课、关闭学生端或重启电脑后仍然保持，
   直到老师点击「解除桌面锁定」。解除后，会尝试恢复该学生机锁定前保存的壁纸和相关设置。
5. 学生端始终显示「课堂管理运行中」，并可看到「已锁定默认桌面」状态。不会隐藏程序，也不会做键盘记录。
6. 说明：锁定写入当前登录用户的策略。若学生账户具有管理员权限，仍可能自行改注册表或用其它工具解除。
   机房请尽量使用普通学生账户。本功能不强制禁止移动桌面图标。


十、常见问题

1. 控制台打不开或页面异常：请改用 Chrome / Edge，不要用 IE。
2. 学生机找不到教师机：确认同一机房局域网，核对学生填写的教师机 IP，并检查防火墙端口。
3. 手机打不开：手机必须连机房 WiFi，地址用教师机的局域网 IP，不要用 127.0.0.1。
4. 默认桌面没有应用到某台学生机：确认该机已加入课堂（已允许加入），并且学生端窗口仍在运行；
   让该机重新打开学生端或重启后再看。解除锁定请用老师控制台上的「解除桌面锁定」，不要只关学生端程序。
5. 安装不了或双击后没反应：
   - 先确认 32 / 64 位有没有选对（见第一节）；
   - 改用本版「用户目录安装」的新安装包，或改用绿色版解压到 C:\GuoyiTeacher（或 C:\GuoyiStudent）；
   - 需要 Windows 7 SP1；未打 SP1 时仍可能失败。
6. 教师机启动失败（窗口一闪、弹出错误，或黑窗口里提示失败），常见于 Windows 7：
   请用记事本打开安装目录下的 start_teacher.log，并把该文件发给开发者。
   默认安装目录：
     C:\Users\用户名\AppData\Local\GuoyiClassroom\Teacher
   例如：C:\Users\Administrator\AppData\Local\GuoyiClassroom\Teacher
   请使用 1.2.2 或更新的教师机安装包（已修复 Win7 上无法加载 pydantic 组件的问题）。
7. 学生机启动失败：同样请把安装目录下的 start_student.log 发给开发者。
   默认安装目录：
     C:\Users\用户名\AppData\Local\GuoyiClassroom\Student
   已经在 Windows 10 / 11 上正常使用 1.2.1 学生端的电脑，不必立刻重装；
   若以后有 Windows 7 学生机，请改用 1.2.2 或更新的学生端安装包。
